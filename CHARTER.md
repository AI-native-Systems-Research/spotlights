# CHARTER

This repo is the spine of the Spotlight Engine. It hosts multiple bundle charters because bundles C (candidates), D (changes), E (validation), and F (orchestration) live here as subpackages until they graduate to their own repos.

See `src/spotlights_engine/charters/` for the per-bundle charters:

- [Candidates](src/spotlights_engine/charters/candidates.md)
- [Changes](src/spotlights_engine/charters/changes.md)
- [Validation](src/spotlights_engine/charters/validation.md)
- [Orchestration](src/spotlights_engine/charters/orchestration.md)

The charters themselves are drafted separately; this file is a directory.
